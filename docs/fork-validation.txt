LIMITATIONS
- No complete TTS synthesis across every engine, voice-cloning quality test,
  or Windows/Linux CUDA/ROCm execution. Keeping an engine available and resolving
  its dependencies is not equivalent to validating every model and accelerator.
- Pins prevent unreviewed upstream code changes; downloaded Python is not a
  sandbox. Optional translation agents still run with the user's OS privileges.
- User-owned engine environments are not silently rewritten and retain their
  own security status. Use the fork's managed installation/repair paths.
- No claim of zero vulnerabilities, universal model compatibility or model
  commercial-use clearance. Model download/access terms remain separate.
